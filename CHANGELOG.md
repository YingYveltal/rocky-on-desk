# Changelog

## v1.0.1 (2026-05-07)

### Bug Fixes

- **PowerShell hook error**: Removed `shell: "powershell"` from hook command generation on Windows. Previously, hooks generated by the Windows app were incompatible with `claude` running inside WSL (which uses `claude.exe` but reads the same `settings.json`). Commands are now plain `node` invocations without a shell wrapper.
- **WSL connectivity**: HTTP server now binds to `0.0.0.0` instead of `127.0.0.1`, and hook scripts auto-detect WSL to use the Windows host IP (from `/etc/resolv.conf`). Previously, `127.0.0.1` inside WSL pointed to the WSL VM loopback, not the Windows host, so hooks could not reach the Rocky server.
- **tmux support**: Added `tmux` and `tmux: server` to terminal process names so PID resolution works when Claude Code runs inside a tmux session. Previously, the hook's parent-process walk would miss the terminal and resolve to the wrong PID.

## v1.0.0 (2026-05-07)

Initial public release.

### Features
- **Rocky theme** — 18 animated SVG states: idle, thinking, working (3 tiers), sleeping (5-stage sequence), juggling, carrying, sweeping, error, happy, notification, click reactions
- **Rocky Domed theme** — Rocky with protective xenonite dome, same animation set
- **Sound effects** — 5-word Rocky vocabulary across both themes (complete, confirm, error, thinking, waking)
- **Cursor tracking** — Sonar sensor crystals track cursor position
- **Working tiers** — Typing (1 session) → Juggling (2+) → Building (3+)
- **Full sleep sequence** — Yawn → Doze → Collapse → Sleep → Wake
- **Click reactions** — Drag to dangle, double-click to flail
- **Hook state mapping** — Tool-type differentiation (Read→thinking, Agent→juggling, etc.) + probabilistic rare-state sprinkles

### Build
- Windows x64 NSIS installer (`Rocky-on-Desk-Setup-x64.exe`)
- macOS DMG
- Linux AppImage + deb
- GitHub Actions CI/CD with auto-release on tag push
