## Rocky on Desk v1.0.0

Desktop pet of Rocky the Eridian engineer from *Project Hail Mary*.

### What's New

First public release of Rocky on Desk, a custom theme built on the [clawd-on-desk](https://github.com/rullerzhou-afk/clawd-on-desk) framework.

**Two themes included:**
- **Rocky** — Classic spherical rock body with golden sonar crystals
- **Rocky Domed** — Rocky with a protective xenonite dome (as seen on the *Hail Mary*)

**18 animated states** — idle, thinking, working (3 tiers), sleeping (5-stage sequence), juggling, carrying, sweeping, error, happy, notification, double-click, drag.

**Sound** — 5-word Rocky vocabulary: complete, confirm, error, thinking, waking.

### Installation

Download the installer for your platform and run it. After launching, install the Claude Code hooks to make Rocky react to your coding agent:

```bash
cd rocky-on-desk
node hooks/install.js
```
